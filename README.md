# 🦋 GiglowSpa – Sitio Web de Belleza y Tratamientos Estéticos

![GiglowSpa](https://img.shields.io/badge/Proyecto-GiglowSpa-ec8acb)
![Estado](https://img.shields.io/badge/Estado-En%20desarrollo-9b83d5)

## 🌸 Descripción del proyecto

**GiglowSpa** es un sitio web diseñado para un negocio dedicado a ofrecer tratamientos estéticos y servicios de belleza profesional.

Su objetivo es proporcionar a los clientes un espacio digital elegante, moderno y accesible, donde puedan conocer los servicios disponibles, descubrir información sobre el negocio y solicitar una cita de manera sencilla mediante WhatsApp.

El diseño utiliza una identidad visual femenina y delicada, con tonos rosados y lilas que transmiten belleza, bienestar y confianza.

## 🎯 Objetivo

Desarrollar una plataforma web responsiva que permita presentar los servicios de GiglowSpa, fortalecer su presencia digital y facilitar la comunicación entre el negocio y sus clientes.

## ✨ Características principales

- **Página de inicio:** Presentación visual del negocio y sus servicios.
- **Quiénes somos:** Sección informativa sobre GiglowSpa.
- **Servicios:** Presentación de los 8 tratamientos estéticos disponibles.
- **Agendar cita:** Acceso directo a WhatsApp para solicitar información y programar una cita.
- **Diseño responsivo:** Interfaz adaptable a diferentes tamaños de pantalla.
- **Identidad visual:** Diseño moderno con una paleta de colores rosa, lila y blanco.
- **Experiencia de usuario:** Navegación intuitiva y elementos visuales que facilitan la interacción.

## 🛠️ Tecnologías y herramientas
